## Fixture record shape

Every vendored file is a JSON array of Django-style fixture records:

```json
{ "model": "api_v2.<lowercasemodelname>", "pk": "srd-2024_<slug>", "fields": { "...": "..." } }
```

`pk` values are prefixed `srd-2024_`; `packages/content/src/upstream.ts#pkSlug` strips that
prefix and normalizes the remainder to the pack slug charset (`^[a-z0-9][a-z0-9-]*$`).
