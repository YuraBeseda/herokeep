# hk-icon

Renders one icon from the vendored [game-icons.net](https://game-icons.net) sprite
(`apps/web/src/assets/icons/sprite.svg`, generated by `apps/web/tools/build-sprite.ts` —
see `apps/web/vendor/game-icons/SOURCE.md`). Purely decorative: it renders
`aria-hidden="true"` and carries no accessible name of its own — a consumer that needs
one (e.g. `hk-icon-button`) supplies it separately.

## Usage

```html
<hk-icon icon="gi:crossed-swords" />
```

Sized `1em` square via `width`/`height` and painted with `fill: currentColor`, so it
inherits the surrounding text's font-size and color — set both on an ancestor to resize
or recolor the icon.

## Inputs

| Input  | Type                | Default | Notes                                                                     |
| ------ | ------------------- | ------- | ------------------------------------------------------------------------- |
| `icon` | `string` (required) | —       | A `gi:<slug>` id, e.g. `gi:crossed-swords`. Throws if not `gi:`-prefixed. |

## Do / Don't

Do source `icon` values from `packages/content/src/icons/icons-map.json` (or an entity's
own icon field once content resolution passes one through) rather than hand-typing
slugs — the map is the only place slugs are verified against what's actually vendored.
Don't pass a bare slug (`"crossed-swords"`) or any other prefix; `hk-icon` throws rather
than silently rendering nothing, since a missing `gi:` prefix is always a caller bug, not
runtime content.

## Adding a new icon

`hk-icon` only ever resolves ids already baked into the sprite at build time — it does
not fetch or discover icons at runtime. To use a game-icons.net icon that isn't vendored
yet: find its real `<author>/<slug>.svg` path in the pinned `game-icons/icons` commit
recorded in `apps/web/vendor/game-icons/SOURCE.md`, download it into
`apps/web/vendor/game-icons/<author>/<slug>.svg`, add the `gi:<slug>` value wherever it
belongs in `packages/content/src/icons/icons-map.json`, then run
`pnpm --filter web build:sprite` and commit the regenerated `sprite.svg`/`authors.json`
alongside the vendored file.
